## STAGE -1 — INTAKE RULES (v1.1-G; mandatory before any score is quoted)

1. **County-auditor year-built lookup** for every parcel — kills the unknown-vintage [est] problem. The vintage ramp (Stage 1) needs a real year; UNK defaults to 1995 — the ramp's oldest-vintage endpoint, a **65% discount floor** (linear vintage ramp: 65% at/below 1995 → 60% at/above 2005, recalibrated 2026-07-14 from the retired 30%/25% cliff; see STAGE 1 Basis floor) — and is flagged in QUESTIONS FOR GABRIEL. *(v4.6: corrected stale "conservative 30% floor" language that predated the 2026-07-14 recalibration — this item previously described the retired ramp, not the current one.)*

3. **Dual-brokerage price conflict check (v3.4):** if research surfaces more than one active listing for the same property at different prices, halt Economics scoring (Basis and Yield) and confirm the authorized listing agent and current ask before proceeding. Document which listing carries NOI disclosure — a listing without NOI cannot support a Yield score. Do NOT average conflicting prices or assume the lower figure is current without direct broker confirmation. Record the discrepancy and source in the QUESTIONS FOR GABRIEL block.

4. **Data Provenance & Conflict Register (v4.0) — extends Rule 3 from price-only to all material fields:** whenever any two sources disagree on a load-bearing field — year built, GBA/office SF, clear height, power, cranes, or any other material physical/vintage fact, not just price — log it to the Data Provenance & Conflict Register (columns: field / OM value / CoStar value / county-auditor value / value used / basis for choice). Required on every FULL-mode memo (IC MEMO STRUCTURE §3) whenever a conflict exists; never silently pick one source and drop the other. Default resolution order absent a documented reason otherwise: county-auditor record wins on vintage/legal facts; a physical on-site observation or a signed lease overrides a marketing OM claim; state the basis for choice explicitly in every row.

5. **Deal-decision-ledger precedent check (v4.2; SCREEN mode only, before scoring):** read `memory/deal-decision-ledger.md` in full and cross-check the candidate against every existing row's "Buy-box rule validated / refined" column — a candidate sharing geography, asset type, seller-motivation signal, or a named rule (e.g. size-cap breach, dollar-store/DG net-lease pattern, materially-impaired Phase II) with a prior decided row is a precedent hit. Cite matching precedent rows by date + deal name directly in the output scorecard (Stage 2 block), not just in prose — this is what makes the firm's revealed buy-box preferences compound instead of being re-litigated screen to screen. No precedent rows found is a valid, statable outcome — say so explicitly rather than omitting the check.

6. **SF/GBA ingestion-time variance check (v4.6):** at ingestion — before any score is quoted — diff every disclosed building SF/GBA figure across the OM, CoStar, and any county-auditor/parcel record already in hand. Compute variance = |max − min| ÷ min. **≤2%** → proceed, no flag (normal rounding/measurement noise; Stage 2.6 item 3's >2% LOI-stage reconciliation still applies before the walk price is finalized). **>2% and ≤5%** → proceed, but flag the variance and the figure used in QUESTIONS FOR GABRIEL and the Data Provenance & Conflict Register (Rule 4). **>5%** → **HARD STOP:** halt Basis and Yield scoring (both denominators depend on SF), cap the verdict at **T2 WATCH**, and require the conflict resolved — via county-auditor record, a survey, or direct broker confirmation — before Combined can be finalized. Distinct from STAGE 2.6 item 3 (LOI-stage reconciliation, >2% threshold, which promotes a screen-time estimate to an LOI-ready verified fact): this rule exists so a >5% SF conflict is never silently carried through an entire SCREEN/FULL cycle on an unexamined denominator. Validation: Pike Plaza #1 (5051 Pike Plaza Rd, Indianapolis IN) — OM stated 32,854 SF vs. CoStar 25,943 SF, a 21% variance that went undetected until manual cross-read of both source documents; this rule exists to catch that class of error before it ever reaches the scorecard.

7. **Scanned / no-text-layer OM check (v4.7, 2026-08-02):** before any extraction, run `pdfinfo` on every uploaded OM or broker package. If the producer is "Microsoft: Print To PDF" (or any other rasterizing producer), or if `pdftotext` returns empty, the document has **no text layer**: extract by page-image render (`pdftoppm -png -r 110`) and visual read, page by page — a failed text pull is NEVER evidence of an empty or unreadable document. Tag every figure obtained this way `[OM-visual]` in the facts file; those figures carry transcription risk and must be reconciled against county/CoStar sources per Rule 4 (Data Provenance & Conflict Register). Note the irony explicitly in the Data Provenance register whenever it occurs: Print-to-PDF is prohibited for ORA outbound deliverables (see IC MEMO STRUCTURE) precisely because it strips the text layer. Validation: the 1518 K St NW OM (Feldman Ruel, 31 pp) arrived as Print-to-PDF; every financial figure was extracted visually and cross-verified against DC OTR records.

8. **Zoning district + current assessed value at intake (v4.14):** before any score is quoted, pull two figures for every parcel and record both in the facts file — (i) the **zoning district from the municipality's live zoning GIS layer**, never the assessor's zoning field, which goes stale; and (ii) the **current assessed value and tax bill actually on the roll**. Use `ora-flood-zoning-dd` for (i) and `ora-millage-lookup` for (ii); both already exist and neither is expensive. **Two failure classes this catches, both of which are invisible to Stage 2.5 because Stage 2.5 runs after scoring has begun:** (a) an industrial building sitting in a **commercial or mixed-use district**, where the existing use is legal nonconforming and a statutory discontinuance clock (12 months in WI/OH/IN under the standard Euclidean-enabling statutes) converts a re-letting problem into a re-entitlement problem — this is a basis-level fact, not a DD detail; (b) a parcel carrying an **anomalous assessment** — exempt coding, $0 value, a stale or absent record — which invalidates any pro-forma tax computed by trending an in-place bill, and can carry retroactive omitted-property exposure. Either finding caps the verdict at **T2 WATCH** until resolved and must appear in QUESTIONS FOR GABRIEL. Validation: 3700 Kinsman Blvd, Madison WI (2026-08-22) — zoned **CC (Commercial Center)**, a CC island inside an IL corridor with the FedEx use very probably legal nonconforming under Wis. Stat. 62.23(7)(h); and carried by the City of Madison as **EXEMPT with $0 assessed value for both 2025 and 2026** with no valid Wis. Stat. 70.11 exemption paragraph. Both facts were material to the verdict, neither appeared in the OM, and an Acquisition Proposal and a drafted LOI had already gone out at $3,800,000 before either surfaced. (Originally proposed to wire into `verified-deal-recon`; placed here instead because that skill is absent from the synced skill set on this surface. STAGE -1 fires on every mode, not only pre-screen, which is strictly better coverage.)

## STAGE 0 — GATES (Ruling 5: NO HARD KILLS — breaches are FLAGS, screened as exceptions; only Gabriel kills a deal)

A gate breach = prominent flag + screen/score as exception anyway; verdict label **GATE-FLAGGED** (never KILLED). Pure out-of-market junk gets flagged-and-deprioritized rather than scored in depth — judgment, not termination.

**Institutional benchmark note (v4.3):** bank/institutional CRE underwriting (per the OCC Comptroller's Handbook) generally hard-gates environmental, structural, and zoning defects — a loan simply isn't made until they clear. Ruling 5's flag-not-kill philosophy is a **deliberate, correct divergence from that norm, not an omission** — it is the specific mechanism that lets an all-cash, generational-hold family office look at deals a bank or fiduciary institutional fund must auto-reject, which is a real competitive edge. Do not let a future "institutional hardening" pass walk this back toward bank-style hard gating; the two underwriting postures serve different capital with different constraints.

2. **Size/Price:** $500K–$10M single asset; ≤$15M multi-building portfolio of **2–5 buildings (Amendment H, v1.1-H, ratified 2026-10-30)**; <50,000 SF per building. A portfolio over $15M or over 5 buildings = gate flag (Ruling 5). Per-building tests, pricing and governor handling: STAGE 1 Portfolios, Amendment H.

3. **Market:** Established clusters (Columbus, Cincinnati, Kansas City, Indianapolis, Maryland/DC, Madison WI) + entry clusters (Grand Rapids, Richmond, Des Moines, **Louisville KY**, **Chicago–Greater Cook County IL**). Satellites: ONLY within 30 min of an ESTABLISHED cluster, Market pts capped at half. **Ruling 3: entry clusters earn NO satellite eligibility until ORA's first closed deal validates the cluster.** *Louisville entry rationale (June 2026): B+ metro grade; UPS Worldport permanent anchor; GE Appliances $490M reshoring June 2025; Riverport 13–14 active listings at $3.90–$5.00 NNN (40% below MSA avg); adjacent to Indiana established cluster. Kentucky outside preferred-state list — treat as entry cluster, NOT established.* **Louisville KY ratified as the 10th canonical cluster in `target-markets.json` v1.7 (Gabriel, 2026-08-05) — the cross-skill split flagged 2026-07-16 (ora-skill-text-audit F3/F4) is closed; deal-comparison, market-monitor, rent-comp, daily-brief, and the Notion Acquisition Pipeline Tracker "Market" / Owner Outreach Queue "Metro" selects (both updated the same session) all recognize Louisville as a target cluster now.** **Chicago–Greater Cook County IL = 11th canonical cluster (target-markets.json v1.11, ratified 2026-09-29) — ENTRY; scope = all of Cook County; collar counties are NOT satellites until a first Cook close (Ruling 3).** **OBSOLESCENCE-WATCH (v4.3, reported not scored):** Prologis Research ("Obsolescence: The Implications for Global Logistics Real Estate") names Columbus and Indianapolis specifically as markets with low barriers to new supply and elevated obsolescence rates for existing stock — directly relevant since these are ORA's two highest-fit established clusters. **This cuts both ways, not just one:** the same report documents aging bulk-distribution stock in exactly these markets migrating into light-industrial use as it ages out of big-box service — a demand tailwind for ORA's shallow-bay product as much as a competing-supply risk (subdivided former bulk space competing with purpose-built shallow-bay). Flag both sides in the pre-mortem for any Columbus/Indianapolis deal near the vintage-ramp floor; do not treat low-barrier-market obsolescence as a one-directional negative.

6. **Other:** ground lease <30 yrs; remediation >20% of price; automotive use; child-use without safety review; retail-only; office-only. *(v4.40, 2026-10-29: retail-only is screened only as land-heavy quasi-IOS, land ≥40% of all-in basis, else GATE-FLAGGED and deprioritized — the operative text is SKILL.md Stage 0 Gate 6; origin 7846 Dixie Hwy.)* **Automotive use, retail-only, and office-only additionally trigger STAGE 2.9 (Alternative Asset Class Track, v4.6) alongside standard scoring** — the industrial-calibrated Basis/Yield floors below remain the deal's governing test, but a parallel land/redevelopment-value read is warranted for this asset subclass; see STAGE 2.9.

## STAGE 1 — FLOORS (flags, not kills — Ruling 5; computed per v1.1-C)

  - ⚠️ **RAMP RECALIBRATED 2026-07-14 (30/25 → 65/60) — THE FLOOR % AND THE DENOMINATOR ARE A MATCHED PAIR.** The old 30/25 ramp was calibrated against RCT v02's *understated* denominator. RCT v03 corrects that denominator (roughly doubling it, per the coherence test). Leaving the ramp at 30/25 against the corrected table would have set the Columbus floor at **$160.76/SF** — a price at which *every* candidate in the buy-box "clears." **A floor that passes everything is not a floor.** The ramp was therefore re-solved to preserve the firm's *revealed* selectivity: ORA's existing clearing prices imply a **mean ~64% discount** to true replacement, not 25–30%. **The 25–30% language was an artifact of a wrong denominator, never a statement of the strategy.** ORA buys at roughly **35–40% of true all-in replacement cost** — say that in IC memos and lender packages; it is a far stronger fact than "a 25% discount."

  - **Net effect of the correction** (v02+30/25 → v03+65/60): **Maryland tightens ~23%** (it had been the most over-generous market) · **Grand Rapids loosens ~16%** and **Indianapolis ~7%** (both had been unfairly harsh) · Columbus, KC and Madison tighten modestly (~3–8%) · Richmond and Des Moines are ~flat. Every move is in the direction the primary-source evidence demands.

- **Renovation effective-vintage rule (Waukee IA audit finding, resolved):** a material renovation shifts the year used for the vintage ramp. Compute renovation spend as a % of that market's construction-type-adjusted RCT v03 POINT replacement cost (POINT × multiplier + adders; "R%"). For an unknown construction type, R% is computed at ×1.00 (the largest denominator): a lower multiplier raises R%, pulls the effective vintage later and lowers the floor, so the unknown-type shortcut must not relax the floor below a checked building's. **R% < 5%** → routine capex, no shift, use the actual year built. **R% ≥ 25%** → full reset, use the renovation-completion year as the effective vintage (treat as newly built for ramp purposes). **5% ≤ R% < 25%** → linear interpolation: effective vintage year = actual year built + [(R% − 5%) ÷ (25% − 5%)] × (renovation year − actual year built). Example: a 1991 building with a 1998 renovation costing 30% of the type-adjusted RCT v03 POINT clears the 25% full-reset threshold → effective vintage = 1998. Document R%, the renovation year, and the resulting effective vintage on every screen where this rule is invoked; unverified/asserted renovation spend gets [est] and blue-cell discipline like any other input.

- **DSCR floor (per-property governor — v3.8; reported on every UNDERWRITE, not just at refi sizing):** post-refi DSCR must be ≥1.25x at the market-rate refi terms in UNDERWRITING CONVENTIONS (LESSER of 65% LTV per-property and 1.25x DSCR). Report actual computed DSCR alongside the IRR floor line on every screen and underwrite. Breach = flag (Ruling 5), not kill, but state the compensating factor if pursued. Since v4.33 this is the only Stage 1 floor computed with debt layered in; Yield, Basis and the (now unlevered) IRR floor are unlevered (see UNDERWRITING CONVENTIONS note). Note: this is the per-property governor — the separate portfolio-aggregate 40% LTV governor is checked at STAGE 2.3, not here.

- **Carrying-cost floor (FLAG, not kill — per Ruling 5):** stabilized total OpEx ≤ **$4.00/SF/yr**, computed on the **pro-forma reassessed property tax at ORA's purchase price** (never the seller's in-place bill) per the State Reassessment Matrix below. Above $4.00/SF → label **CARRY-FLAGGED**; state which component drives the overage and how recovery structure (NNN vs. gross/MTM, vacancy carry) absorbs it. Reassessed tax flows through NOI → the Yield and IRR floors automatically (no double-count).

- **Portfolios:** every building individually clears floors at its **allocated price**, then score the blend. **Allocation method (in priority order):** (1) if credible per-building NOI exists → allocate by **stabilized NOI share**; (2) if NOI is missing or unreliable → allocate by **replacement-cost-weighted GBA** (building SF × construction-type-adjusted RCT v03 POINT for that market ÷ Σ across all buildings); (3) fall back to **raw GBA share** (building SF ÷ portfolio SF) only when construction quality is unknown (an unknown construction *type* is not that case: allocate by (2) at the strictest applicable multiplier). State which method was used. A vacant building in an otherwise-leased portfolio is always allocated by method (2) — method (1) would assign it near-zero basis, which is incorrect.
  - **Amendment H — small portfolios (v1.1-H; Gabriel in-turn 2026-10-30, Deal Sourcing Expansion Plan §6 and §10, ratified as drafted; RE-4.40-1).** Scope: **2–5 buildings sold together in one transaction, ≤$15M total** (STAGE 0 item 2; a portfolio over $15M or over 5 buildings is a gate flag). (i) **Per-building test:** EACH building individually passes the single-asset buy-box (sub-50,000 SF, Class B/C, flex/shallow-bay) — the STAGE 0 product, size, physical, flood and other gates — and the STAGE 1 floors. A breach by any building flags the whole portfolio GATE-FLAGGED / FLOOR-FLAGGED and names the building; under Ruling 5 that is a flag, never a kill, and only Gabriel decides whether to carve the building out. The $500K–$10M single-asset price band is not applied per building; the portfolio carries the ≤$15M ceiling. (ii) **Pricing:** price each building on its own first (its own walk price under the floors); the sum of those walks is ORA's base portfolio price. For ORA's offer, each building's allocated price in the floor test IS its own walk (plus its share of any premium), so the offer never fails the per-building floor test merely because an NOI-share allocation shifts price between buildings; allocation methods (1)–(3) allocate a seller's single asking price and any premium. A portfolio premium above the sum is allowed only if the blended stabilized YoC at the premium price still clears the existing Yield floor (stabilized YoC >8% on full all-in); report the premium in $ and %, and the blended YoC. The portfolio `Walk Price` read by loi-generation QC #23 and Phase 6c is the sum of walks plus any premium that clears this test; state both figures. (iii) **Governors UNCHANGED:** DSCR ≥1.25x per property, the 65% per-property refi ceiling, and the 40% aggregate LTV, which is checked post-close at the portfolio level by the existing STAGE 2.3 Part A test. (iv) **Ruling 3 still applies:** a building in an entry cluster earns no satellite eligibility until ORA's first close validates that cluster, and buying it inside a portfolio does not confer eligibility. **Why:** small multi-building trades were already inside the ≤$15M gate, but nothing stopped a strong building from carrying a weak one through a blended score or a blended price. Amendment H closes that by making each building stand alone before any blend. No scorecard weight, floor or governor constant moved.

- **Priced, no-NOI:** score Yield = 0 (documented no-NOI convention — never left null); Basis scores normally at the deal's scoring price (ORA's walk price per the standing convention, else the disclosed price) — never a YoC-solved price, which requires an NOI this case does not have.

- **Unpriced AND no-NOI (no-price-no-NOI Basis rule, Hamilton golden-set finding, 2026-09-12):** do NOT solve a walk price from an externally-sourced or linked-record implied NOI (e.g. a pipeline row's Purchase Price × Cap Rate) — that imports a live/adjacent-record assumption the frozen-facts SCREEN discipline exists to exclude. Eval-harness replays of one unpriced, no-NOI golden deal all used the same implied NOI yet split on whether a Basis score may rest on a walk price solved from it, swinging Combined 7–8 pts across four runs (see `acquisition-underwriting-eval-harness/golden_set/11850-hamilton-ave-cincinnati-oh.json` `known_gaps`). Score Yield = 0 (same no-NOI convention) and **Basis = null** with a `[DATA-GAP: no price, no NOI]` flag — Basis is genuinely not computable from frozen facts alone here, not floor-solved. A broker/pipeline-implied cap rate, if one exists, may be reported as a labeled SENSITIVITY BAND alongside the score — never as the scored Basis input itself.

## STAGE 2 — SCORECARD (100 pts; REPORT AS QUALITY + ECONOMICS + COMBINED per v1.1-A)

**Quality (price-independent, max 55 always)** = Product 20 + Market 12 + Seller 10 + Tenancy 7 + VA 6–13. **Vacant-deal arithmetic (Waukee IA audit finding, resolved):** the prior "62 if vacant" figure was wrong — it double-counted Tenancy's points instead of reallocating them. When 100% vacant, Tenancy scores 0 (no in-place tenant to score) and VA absorbs Tenancy's forfeited 7 pts 1:1 (VA 6 → 13, per the scorecard table row 7). Quality max is **55 in every case** — vacancy shifts points between Tenancy and VA, it never adds points — which is what makes Combined = Quality(55) + Economics(45) = 100 close correctly in both the occupied and vacant case.

**Economics (price-dependent, max 45)** = Basis 25 + Yield 20, at the ORA-actionable price (an unknown construction type scores Yield at the ×1.00 walk; Basis stays strict).

**Combined = Quality + Economics** (identical to the v1.0 100-pt score). Unpriced deals rank primarily on Quality; show Economics as a band across the plausible price range.

**IRR reporting (v3.8; unlevered floor line v4.33):** report the 10-yr unlevered IRR floor line (value · floor · UST basis and date) and levered IRR — 5-yr and 10-yr, both pre-tax and after-tax/cost-seg scenarios — alongside Combined and Expected Score on every SCREEN and SNAPSHOT output, not only UNDERWRITE/FULL, so return dispersion is visible for pipeline triage even between deals with similar Combined scores. IRR remains floor-only (Stage 1; the floor is 10-yr unlevered since v4.33, levered lines are reported only), NOT point-scored — scorecard weights are unchanged from v1.1. Converting IRR from floor to a scored Economics component is a calibration-governed decision reserved for the annual December back-test (Outcome Feedback, v1.1-E); do not hand-adjust weights mid-cycle.

**Batch-ranking compression flag — Yield = 0 (v3.4):** when >50% of deals in a ranked batch have Yield = 0 (no NOI disclosed), the ranking is driven by Quality + Basis only — not a full 100-pt scorecard. Flag this explicitly at the top of any batch-ranking output. Relative rank within a ≤5-pt Combined band is below estimation precision when Yield is uniformly zero. Prioritize deals with NOI disclosure for broker call time; call out any deal where a disclosed yield would materially move rank.

Recalibrating the floor without recalibrating this scale would have made full Basis points unreachable.)* |

**Clear/loading matrix:** units <3,500 SF → 14'+ clear; 3,500–10,000 → 16'+; >10,000 → 18'+ (higher better). Loading: 1 drive-in per unit <5,000 SF; 1 dock/10,000 SF; more is better. Truck court 100' ideal; <60' ≈ 0 site pts (no kill). Construction: block/tilt-up/brick full credit; PEMB ≈ half, never kills; an unknown construction type scores as PEMB, and its Yield (only) is scored at the ×1.00 walk (Basis stays strict).

**Seller/Motivation signals (any credible signal scores; stack for more):** distress/life events (estate/probate, divorce, partnership dissolution, lender pressure/REO, tax delinquency, DM fatigue); market evidence (price cuts, DOM >120, failed contracts, broker churn); inexperience (residential/local-only brokerage on a commercial deal, no/bad OM, unpriced, mispriced vs auditor/comps, $0-basis long-hold non-institutional seller); debt and occupancy signals (v4.33): estimated loan maturity ≤24 months `[est]` (finalist recorder check, `county-parcel-screen` v1.5 step 8 — never a bulk feed) and an occupying owner-user open to a sale-leaseback.

**Owner-user-vacating (named signal):** an owner-occupant disposing of its OWN now-vacant building is structurally motivated (carrying a non-income building bleeds an operator) and typically mispriced HIGH at listing (anchored to original cost/replacement, not a lease-up buyer's residual), often paired with inexperienced/local brokerage. Scores high in Seller/Motivation; compounds with DOM>120, price cuts, failed contracts.

**Price-watch trigger (owner-user-vacating + basis/price fail):** do NOT cold-PASS. Log the ORA walk price at the basis floor and the implied % gap-to-ask in the Notion deal record. Re-engage when a price cut brings ask within ~5% of ORA walk AND executed/starting rents verify (amendment G). P(exec) rises materially only once the cut lands — move up the Expected-Score pipeline sort at that point, not before. Feeds ora-passed-deal-tracker. A walk solved before v4.37 is re-solved first (SKILL.md, Pre-v4.37 walks). Validation: 2196 Port Sheldon — re-engage at ~$1.45–1.50M + verified rents.

Signals also set offer aggressiveness, timing, and P(exec).

**Basis-discount ≠ comp-discount — do not conflate (v3.4):** the Basis score (Stage 1 + scorecard row 1) uses discount-to-RCT-LOW as its input — this measures discount to physical replacement cost of a new building. The Seller/Motivation mispricing signal requires discount-to-executed-resale-comps for the submarket — this measures what buyers actually paid for existing comparable buildings. These are different numbers. A large RCT discount does NOT establish broker mispricing if the resale comp band is near or above the ask; conversely, a modest RCT discount can still reflect mispricing if comps trade at a premium to RCT. Always cite the applicable resale comp band when invoking the mispricing signal; never use RCT as a proxy for comp value.

**IOS return-claim caution (v4.3) — same discipline, applied to a different conflation:** industrial outdoor storage (IOS) macro data — rent growth, vacancy, institutional capital flows — is real and independently sourced across multiple institutional reports. The SPECIFIC return figures circulating in the market to sell IOS as a strategy (8%+ untrended yields, 20%+ IRRs, "2x overall industrial rent growth") are predominantly self-reported by operators and brokers with an obvious promotional interest in the asset class — one institutional investor's own "2x rent growth" claim explicitly admits the underlying market data is immature. Quasi-IOS remains an explicit Stage 0 Gate 1 target profile and scores under Value-Add Optionality (row 7) as designed — but do not let market-circulating IOS return statistics inflate VA scoring confidence beyond what the deal's own verified numbers support. Cite the macro data freely in Edge-scan narrative; treat operator-reported yield/IRR figures as unverified marketing, not comparable data.

**Environmental:** flag + price (Phase I always; Phase II OK with cap; >20% of price = gate flag). NOT scored. **Phase II probability escalators (v3.4):** when any of the following are confirmed at screen, upgrade to "Phase II HIGH probability" and price accordingly before LOI — do not wait for Phase I to trigger it: (i) oil-water separator (OWS) or grease trap on-site; (ii) active UST registry hit (IDEM, MDEP, WDNR, or equivalent state DB); (iii) in-use floor drains in a service bay, wash bay, or manufacturing area; (iv) automotive, petroleum-handling, dry-cleaning, or industrial-solvent SIC tenancy (current or prior); (v) adjacent parcel with confirmed LUST or active plume (subject is a potential receptor). Phase II HIGH probability is not a gate kill (Ruling 5) but requires explicit environmental cost-range estimate and a compensating factor before advancing past SCREEN. **Verdict flag (v3.8):** Phase II HIGH probability sets verdict flag **ENV-WATCH**, displayed in the verdict block alongside CARRY-FLAGGED / DENOMINATOR-SENSITIVE / CONCENTRATION-FLAGGED and carried into VERDICT BANDS reporting until the cost-range estimate and compensating factor are logged.

## STAGE 2.1 — TENANCY BEAR-MODE (v1.1-D; check on EVERY screen)

When market-monitor shows the submarket with **vacancy up >100bps YoY OR two consecutive quarters of negative absorption**: (i) halve Tenancy upside points; (ii) add 12 months of downtime carry to lease-up assumptions (flows into all-in basis). **Report the trigger state (ON/OFF + source + date) on every screen.** **Authoritative source = the `market-monitor` skill** (live vacancy/absorption from CoStar/CBRE/JLL/Colliers quarterly prints). The ranking workbook's Bear-Mode Monitor tab is a **convenience cache only** — if stale (>30 days) or absent, query `market-monitor` directly and cite the live print. ## Pipeline stamping (standing rule — added 2026-08-12)

**This skill previously stamped neither field, despite being named as a stamper elsewhere.** `ora-deal-command-board` STEP 2 has described `Last Activity` since 2026-07-17 as "an explicit date stamped by deal owners and deal-touching skills (loi-generation, deal-execution, acquisition-underwriting, etc.)" — but `loi-generation` Phase 6 and `deal-execution`'s NOTION PIPELINE STAMPING section were the only two that actually did it. Any time this skill acts on a deal that has an Acquisition Pipeline Tracker row (`bcfe4a03`) — a SCREEN verdict, a COMPS refresh, an UNDERWRITE, or a FULL IC memo — update that row:

- **`Last Activity` = today (date-only).** A screen or an underwrite IS deal progress. Underwriting that happens off-Notion (in the model, in a memo) is precisely the case this field exists to cover.

- **`Next Action Date` — only when the verdict carries a date.** Write it into the column, never only into `Next Action` prose. Realistic cases: a T2 WATCH verdict with a re-check date, a STAGE 2.6 pre-LOI DD item with a deadline, an LOI decision date. **If the verdict carries no date, leave the column NULL** — do not invent one, and specifically do not manufacture a date from the tickler habit ("re-check in 30 days") unless that re-check was actually decided. A fabricated date on a live deal record is a Hard-Invariant-7 fabrication, and it is worse than a null here because two downstream tasks now treat this column as a commitment: `ora-deal-aging-sla` STEP 3d flags a past-due date as a missed self-imposed commitment, and `ora-health-guard` block 4d runs its 7-day deadline sweep off it.

Both fields are date-only. Where `Next Action Date` and the `Next Action` prose disagree, `ora-deal-command-board` STEP 2b reports `DATE DIVERGENCE` rather than reconciling — so an inconsistent stamp surfaces as a contradiction for a human to resolve, not as a silent wrong answer.

## v4.33 rationale — underwriting-audit package (Gabriel, in-turn, 2026-10-18)

Origin: the 2026-10-18 acquisition-underwriting audit (external research report plus a read of live doctrine v4.31). Gabriel ratified audit items 2–8 in-turn and excluded item 1 (lifecycle reserves; the $0.15/SF reserve convention stands). These changes were staged for the December back-test; the out-of-cycle ratification is Gabriel's call, and the December session re-confirms every constant below.

- **Unlevered IRR floor.** ORA closes all-cash and its aggregate LTV is near 19% (CAPITAL STRUCTURE CONTEXT). A levered floor computed on a 65% LTV refi therefore tested a capital structure the family does not hold, and the 5-yr levered IRR was dominated by the assumed exit. The new floor is 10-yr unlevered ≥ max(10.0%, UST10 + 550 bps). At the mid-2026 10-yr Treasury of roughly 4.6–4.7% (as reported in CBRE U.S. Cap Rate Survey H1 2026, secondary; FRED DGS10 is the operative source for every floor test) the rate-linked term is ~10.1–10.2%, so the 10.0% minimum and the rate term are close today; the rate term governs if rates rise. The 550 bps spread and the 10.0% minimum are `[EST]`.
- **Suite-Level Rollover & Credit Block.** The prior renewal convention (probability-weighted MTM, 50% capture, no LC, minimal TI) and the absence of a credit-loss line left turnover cost and bad debt out of the cash flow for every occupied deal outside the Lease-Up Block. External anchors: EastGroup FY2025 retention 74.6%, life-of-lease TI/LC $9.84/SF new vs $3.47/SF renewal, bad debt ~30–45 bps of revenue — on tenants averaging ~35K SF. ORA's tenants average ~4,300 SF (≈600K SF ÷ ≈140 tenants), so retention is set lower and credit loss higher. Every default is `[EST]` and is calibrated from ORA's own Tenant DB and PM-portal history at the December back-test.
- **Market rent growth split from escalators.** National industrial rent growth slowed to 1.2% YoY in Q1 2026 (Plante Moran). A 3% figure that served as both contractual bump and market growth would compound the mark-to-market gap; the gap is now captured once, at rollover.
- **FORT-adjusted Basis.** Basis tops out at a ≥76% discount to RCT LOW, which rewards the oldest, cheapest buildings — where functional obsolescence concentrates. FORG measured that risk but sat outside Combined. The multiplier (1.00 / 0.75 / 0.50) is `[EST]`; it changes points only, never the basis floor or walk price, so the frozen SCREEN golden set (no FORG on SCREEN) is unaffected unless FORG is run there.
- **Maryland exit cap 7.25%.** Maryland/DC carried the lowest exit cap in the table while Baltimore showed the weakest fundamentals in ORA's set (Q2 2026 industrial vacancy 8.4% Newmark / 9.3% C&W; CBRE +80 bps YoY; CoStar described a correction in April 2026). +25 bps is the low end of the audit's 25–50 bps range.

Part B thresholds are ratified as flags (Ruling 5). The freeze blocks new canonical clusters only; the scale threshold that lifts it is Gabriel's open decision.
