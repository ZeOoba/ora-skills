## IC MEMO STRUCTURE (FULL mode — canonical 12 sections)

Every FULL-mode IC memo uses these sections in order. DOCX, ORA institutional style; extractable text layer required (Microsoft Print to PDF prohibited). Every figure reconciles to the underwriting workbook and facts file (QC Gate).

**Typographic system (Waukee IA audit finding, resolved — codifies a pattern executed well but never written down):**
- **Headings & inline labels:** DM Sans, bold, Navy #1B2A4A.
- **Body / prose:** EB Garamond, Navy-black #1A1A1A.
- **Metadata lines, system/data callouts, and table cell contents:** IBM Plex Mono, 9pt, gray #555555.
- **Tables:** use a named Word table style (not default "Table Normal") — header row shaded Navy #1B2A4A with white text, body rows banded Parchment #F5F3EF / white alternating. Default "Table Normal" with no shading is a defect, not a style choice — it causes reflow issues and fails the QC Gate.

1. **Executive Summary & Recommendation** — one page: address, price, SF, $/SF, going-in & stabilized YoC, 10-yr unlevered IRR vs its floor (v4.33), levered IRR (both tax scenarios), Combined score, P(exec), Expected Score, and the headline GO / WATCH / PASS recommendation with the single strongest supporting reason. When the seller acquired within 24 months, state ask vs. seller's basis ($ and %) (Stage -1 item 10).
2. **Investment Thesis** — why this deal fits the buy-box and the path to value. 3–5 bullets; no filler.
3. **Property Description** — building(s), GBA, clear height, loading (docks/drive-ins), construction type, year built (county-auditor verified), site/acreage, office %, condition, condo structure if any. **Data Provenance & Conflict Register (v4.0):** a short standing sub-table (field / OM value / CoStar value / county-auditor value / value used / basis for choice), required whenever any two sources disagree on a load-bearing field (Stage -1 item 4) — extends the dual-brokerage price conflict protocol (Stage -1 item 3) from price-only to all material physical/vintage facts.
4. **Market & Submarket Analysis** — cluster tier, vacancy, absorption, rent trend, bear-mode state (ON/OFF + source + date); cite `market-monitor`. For submarket grade, ORA fit rating, and demographics, reference the **Submarket Intelligence Reference** table in this skill (June 2026 deep research; re-validate with live `market-monitor` data) and `markets.md` for any independently ORA-validated figures — no separate `market-intel-[metro]` memory file exists (deprecated 2026-07-11). **Location score (Stage 2.7):** report the Acquisition Location Score composite (1–100) with its 6-component breakdown (highway/intermodal distance, drive-time population/labor, submarket vacancy-rent trend, anchor proximity) and the Last-Mile Suitability score. **Intermodal-weighting caveat:** the composite's 20% intermodal-distance weight assumes rail/intermodal-dependent tenancy and may understate locational fit for last-mile/shallow-bay profiles without rail exposure — weight the Last-Mile Suitability score more heavily in the narrative for those deals. Distance/population/labor figures carry `[est]` unless `CONFIRMED` per Stage 2.7 sourcing discipline.
5. **Tenancy & Lease Analysis** — rent roll, WALT, in-place vs market rent, MTM/rollover schedule, tenant credit/risk (cite `tenant-intelligence`), renewal economics and expected-value rollover per the Suite-Level Rollover & Credit Block (v4.33: renewal probability and downtime by suite size, renewal TI/LC, credit-loss line, market rent growth Base/Bear/Bull).
6. **Financial Analysis** — going-in & stabilized NOI, cap/value, YoC, unlevered & levered IRR (Bear/Base/Bull, each fully re-levered per MODES/UNDERWRITE v4.0), equity multiple, DSCR; **going-in cap / exit cap / spread line with the INVERTED-SPREAD flag if triggered (v4.0)**; pro-forma reassessed property tax and total carrying cost $/SF, sourced from the workbook's **OpEx & Carrying Cost tab** (v4.0 — single source of truth; a hand-typed `[EST]` tax figure not tied to that tab's cell fails the QC Gate) per the State Reassessment Matrix; cost-seg + 100% bonus after-tax returns (both scenarios, per the after-tax reproducibility convention under UNDERWRITING CONVENTIONS). Pre-tax floors shown unlevered.
7. **Debt & Capital Structure** — all-cash close + per-property refi terms (per UNDERWRITING CONVENTIONS: LESSER of 65% LTV and 1.25x DSCR, fixed at the 10-yr UST + 200 bps (v4.37), 25-yr amort, 5/10-yr term — state which of LTV/DSCR binds), proceeds/return-of-capital, generational-hold liquidity view, the going-in/exit/spread line restated alongside the leverage terms (v4.0 — a negative-leverage/cap-expansion deal should be visible here, not only in §6), and the portfolio-aggregate LTV governor check (40% ceiling, STAGE 2.3) stated explicitly as pass/flag. **Two-basis rule (v4.29, Gabriel 2026-10-16):** the portfolio-LTV line is computed all-cash — the deal adds no acquisition debt to the numerator (it enters the denominator only); §6–§7 returns, levered IRR and DSCR stay levered on the post-close refi above. State both bases explicitly so the reader does not net the refi against the governor. **Informational with-refi line (v4.31, Gabriel 2026-10-17):** also state with-refi portfolio LTV with this deal’s modeled post-close refi added (plus other modeled-not-closed pipeline refis, if known), labeled "informational — non-gating"; the pass/flag against 40% is decided on the all-cash figure only.
7. **Debt & Capital Structure** — all-cash close + per-property refi terms (per UNDERWRITING CONVENTIONS: LESSER of 65% LTV and 1.25x DSCR, 6.50% fixed, 25-yr amort, 5/10-yr term — state which of LTV/DSCR binds), proceeds/return-of-capital, generational-hold liquidity view, the going-in/exit/spread line restated alongside the leverage terms (v4.0 — a negative-leverage/cap-expansion deal should be visible here, not only in §6), and the portfolio-aggregate LTV governor check (40% ceiling, STAGE 2.3) stated explicitly as pass/flag. **Two-basis rule (v4.29, Gabriel 2026-10-16):** the portfolio-LTV line is computed all-cash — the deal adds no acquisition debt to the numerator (it enters the denominator only); §6–§7 returns, levered IRR and DSCR stay levered on the post-close refi above. State both bases explicitly so the reader does not net the refi against the governor. **Informational with-refi line (v4.31, Gabriel 2026-10-17):** also state with-refi portfolio LTV with this deal’s modeled post-close refi added (plus other modeled-not-closed pipeline refis, if known), labeled "informational — non-gating"; the pass/flag against 40% is decided on the all-cash figure only. **Debt taken at close (v4.36):** if the LOI, PSA or a term sheet shows ORA assuming a loan, taking a seller carry-back or closing a new acquisition loan, add one line noting that the pre-close INTERIM manual LTV test (`debt-management/references/ltv-interim-netting-checklist.md`, run by Gabriel) is required before signing; do not add that loan to the all-cash governor figure.
8. **Risk Analysis & Pre-Mortem (MANDATORY)** — assume the deal failed; rank failure reasons by probability-weighted damage; mitigant or kill-switch for each. Include the MI Prop A line for MI deals.
9. **Value-Add & Edge Scan** — all four Stage 3 categories (Land & Entitlement · Income · Seller-Side · Infrastructure); IC memo floor = at least 1 named item per category (4 total minimum) or an explicit "none identified — checked X, Y, Z" per empty category. This is a higher bar than the screen floor of ≥3 total named items. **Discount Decomposition sub-block (v4.22):** the STAGE 3 table in `SKILL.md` (comp-band and RCT discounts stated separately, only the comp-band discount decomposed; driver → CURABLE / INCURABLE / UNK → discount attributed → cure cost → value restored, each `[est]` + sourced or UNK; close-out line with the unexplained residual). Reported, not scored. Carry the §10 RCT discount figure into it; do not re-derive it.
10. **Replacement Cost Analysis** — all-in basis $/SF vs RCT v03 (cite version + market LOW/POINT/HIGH, plus the construction type and multiplier, e.g. "RCT v03 · PEMB ×0.90", with the band shown construction-type-adjusted), discount-to-replacement, vintage-ramp floor, adder schedule applied, DENOMINATOR-SENSITIVE flag status.
11. **Exit / Hold Strategy** — generational hold + refi-liquidity base case; exit cap (market-specific, this table dated 2026-06-20); disposition/1031 only as a sensitivity; no forced-exit assumption.
12. **Recommendation & Next Steps** — restated verdict, offer price and aggressiveness (set by seller signals per Stage 2.2), portfolio-concentration state (Stage 2.3), LOI handoff to `loi-generation` (Gabriel approval ALWAYS required), open DD-Critical items, QUESTIONS FOR GABRIEL block. **Standing bullet (v3.9):** whenever Stage 2.7 spatial/location figures carried `[est]` tags, call for live routing/Census-API confirmation as an open pre-LOI item — an `[est]` distance/population/labor figure does not ride silently into the PSA. **Offer Strategy block (v4.0) — standard on every below-floor / PASS-band-on-price deal:** price-to-clear each binding floor (Basis, Yield, IRR, or DSCR — whichever actually binds), goal-seeked FROM the Sensitivity/Returns tab's own formulas per the UNDERWRITE Model integrity requirement (never a typed-in asserted number), the identified binding floor, an opening bid, and the expected clearing price given the deal's P(exec) band (Stage 2.2 — offer aggressiveness already set by seller-motivation signals). This reuses the existing walk-price discipline (STAGE 1: "Unpriced/no-NOI") and the price-watch trigger / `ora-passed-deal-tracker` linkage (Seller/Motivation section) as a standing IC-memo deliverable, not just a screen-time-only computation.
