## STAGE -1 — INTAKE RULES (v1.1-G; mandatory before any score is quoted)

1. **County-auditor year-built lookup** for every parcel — kills the unknown-vintage [est] problem. The vintage ramp (Stage 1) needs a real year; UNK defaults to 1995 — the ramp's oldest-vintage endpoint, a **65% discount floor** (linear vintage ramp: 65% at/below 1995 → 60% at/above 2005, recalibrated 2026-07-14 from the retired 30%/25% cliff; see STAGE 1 Basis floor) — and is flagged in QUESTIONS FOR GABRIEL. *(v4.6: corrected stale "conservative 30% floor" language that predated the 2026-07-14 recalibration — this item previously described the retired ramp, not the current one.)*
2. **Load-bearing rent/NOI verification:** the NOI figure must be verified against a source document (rent roll, lease, income statement) BEFORE any score is quoted. Basis + Yield share one denominator — 45 correlated points ride on it. Unverifiable → score carries [est] and blue-cell discipline; say so wherever the score appears.
3. **Dual-brokerage price conflict check (v3.4):** if research surfaces more than one active listing for the same property at different prices, halt Economics scoring (Basis and Yield) and confirm the authorized listing agent and current ask before proceeding. Document which listing carries NOI disclosure — a listing without NOI cannot support a Yield score. Do NOT average conflicting prices or assume the lower figure is current without direct broker confirmation. Record the discrepancy and source in the QUESTIONS FOR GABRIEL block.
4. **Data Provenance & Conflict Register (v4.0) — extends Rule 3 from price-only to all material fields:** whenever any two sources disagree on a load-bearing field — year built, GBA/office SF, clear height, power, cranes, or any other material physical/vintage fact, not just price — log it to the Data Provenance & Conflict Register (columns: field / OM value / CoStar value / county-auditor value / value used / basis for choice). Required on every FULL-mode memo (IC MEMO STRUCTURE §3) whenever a conflict exists; never silently pick one source and drop the other. Default resolution order absent a documented reason otherwise: county-auditor record wins on vintage/legal facts; a physical on-site observation or a signed lease overrides a marketing OM claim; state the basis for choice explicitly in every row.
5. **Deal-decision-ledger precedent check (v4.2; SCREEN mode only, before scoring):** read `memory/deal-decision-ledger.md` in full and cross-check the candidate against every existing row's "Buy-box rule validated / refined" column — a candidate sharing geography, asset type, seller-motivation signal, or a named rule (e.g. size-cap breach, dollar-store/DG net-lease pattern, materially-impaired Phase II) with a prior decided row is a precedent hit. Cite matching precedent rows by date + deal name directly in the output scorecard (Stage 2 block), not just in prose — this is what makes the firm's revealed buy-box preferences compound instead of being re-litigated screen to screen. No precedent rows found is a valid, statable outcome — say so explicitly rather than omitting the check.
6. **SF/GBA ingestion-time variance check (v4.6):** at ingestion — before any score is quoted — diff every disclosed building SF/GBA figure across the OM, CoStar, and any county-auditor/parcel record already in hand. Compute variance = |max − min| ÷ min. **≤2%** → proceed, no flag (normal rounding/measurement noise; Stage 2.6 item 3's >2% LOI-stage reconciliation still applies before the walk price is finalized). **>2% and ≤5%** → proceed, but flag the variance and the figure used in QUESTIONS FOR GABRIEL and the Data Provenance & Conflict Register (Rule 4). **>5%** → **HARD STOP:** halt Basis and Yield scoring (both denominators depend on SF), cap the verdict at **T2 WATCH**, and require the conflict resolved — via county-auditor record, a survey, or direct broker confirmation — before Combined can be finalized. Distinct from STAGE 2.6 item 3 (LOI-stage reconciliation, >2% threshold, which promotes a screen-time estimate to an LOI-ready verified fact): this rule exists so a >5% SF conflict is never silently carried through an entire SCREEN/FULL cycle on an unexamined denominator. Validation: Pike Plaza #1 (5051 Pike Plaza Rd, Indianapolis IN) — OM stated 32,854 SF vs. CoStar 25,943 SF, a 21% variance that went undetected until manual cross-read of both source documents; this rule exists to catch that class of error before it ever reaches the scorecard.
7. **Scanned / no-text-layer OM check (v4.7, 2026-08-02):** before any extraction, run `pdfinfo` on every uploaded OM or broker package. If the producer is "Microsoft: Print To PDF" (or any other rasterizing producer), or if `pdftotext` returns empty, the document has **no text layer**: extract by page-image render (`pdftoppm -png -r 110`) and visual read, page by page — a failed text pull is NEVER evidence of an empty or unreadable document. Tag every figure obtained this way `[OM-visual]` in the facts file; those figures carry transcription risk and must be reconciled against county/CoStar sources per Rule 4 (Data Provenance & Conflict Register). Note the irony explicitly in the Data Provenance register whenever it occurs: Print-to-PDF is prohibited for ORA outbound deliverables (see IC MEMO STRUCTURE) precisely because it strips the text layer. Validation: the 1518 K St NW OM (Feldman Ruel, 31 pp) arrived as Print-to-PDF; every financial figure was extracted visually and cross-verified against DC OTR records.

## STAGE 0 — GATES (Ruling 5: NO HARD KILLS — breaches are FLAGS, screened as exceptions; only Gabriel kills a deal)

A gate breach = prominent flag + screen/score as exception anyway; verdict label **GATE-FLAGGED** (never KILLED). Pure out-of-market junk gets flagged-and-deprioritized rather than scored in depth — judgment, not termination.

**Institutional benchmark note (v4.3):** bank/institutional CRE underwriting (per the OCC Comptroller's Handbook) generally hard-gates environmental, structural, and zoning defects — a loan simply isn't made until they clear. Ruling 5's flag-not-kill philosophy is a **deliberate, correct divergence from that norm, not an omission** — it is the specific mechanism that lets an all-cash, generational-hold family office look at deals a bank or fiduciary institutional fund must auto-reject, which is a real competitive edge. Do not let a future "institutional hardening" pass walk this back toward bank-style hard gating; the two underwriting postures serve different capital with different constraints.

1. **Product:** Class B/C industrial — shallow-bay multi-tenant, flex, office-warehouse, OR functional single-tenant ≤40,000 SF (scored EQUAL to multi-tenant). Quasi-IOS single-tenant <20K SF on land-heavy parcels = explicit target profile. Office % never kills if 1-story with adequate clear behind the finish (demo-able); ≤30% ideal.
2. **Size/Price:** $500K–$10M single asset; ≤$15M multi-building portfolio; <50,000 SF per building.
3. **Market:** Established clusters (Columbus, Cincinnati, Kansas City, Indianapolis, Maryland/DC, Madison WI) + entry clusters (Grand Rapids, Richmond, Des Moines, **Louisville KY**). Satellites: ONLY within 30 min of an ESTABLISHED cluster, Market pts capped at half. **Ruling 3: entry clusters earn NO satellite eligibility until ORA's first closed deal validates the cluster.** *Louisville entry rationale (June 2026): B+ metro grade; UPS Worldport permanent anchor; GE Appliances $490M reshoring June 2025; Riverport 13–14 active listings at $3.90–$5.00 NNN (40% below MSA avg); adjacent to Indiana established cluster. Kentucky outside preferred-state list — treat as entry cluster, NOT established.* **Louisville KY ratified as the 10th canonical cluster in `target-markets.json` v1.7 (Gabriel, 2026-08-05) — the cross-skill split flagged 2026-07-16 (ora-skill-text-audit F3/F4) is closed; deal-comparison, market-monitor, rent-comp, daily-brief, and the Notion Acquisition Pipeline Tracker "Market" / Owner Outreach Queue "Metro" selects (both updated the same session) all recognize Louisville as a target cluster now.** **OBSOLESCENCE-WATCH (v4.3, reported not scored):** Prologis Research ("Obsolescence: The Implications for Global Logistics Real Estate") names Columbus and Indianapolis specifically as markets with low barriers to new supply and elevated obsolescence rates for existing stock — directly relevant since these are ORA's two highest-fit established clusters. **This cuts both ways, not just one:** the same report documents aging bulk-distribution stock in exactly these markets migrating into light-industrial use as it ages out of big-box service — a demand tailwind for ORA's shallow-bay product as much as a competing-supply risk (subdivided former bulk space competing with purpose-built shallow-bay). Flag both sides in the pre-mortem for any Columbus/Indianapolis deal near the vintage-ramp floor; do not treat low-barrier-market obsolescence as a one-directional negative.
4. **Physical:** multi-story warehouse; no ground-level access (zero drive-ins AND zero docks); clear height <12'.
5. **Flood:** SFHA on building pad = gate flag. SFHA on excess land = land at $0, proceed. **Ruling 4: land credit = $0 in the basis test until FEMA determination lands; report the verified-dry score as an upside band.**
6. **Other:** ground lease <30 yrs; remediation >20% of price; automotive use; child-use without safety review; retail-only; office-only. **Automotive use, retail-only, and office-only additionally trigger STAGE 2.9 (Alternative Asset Class Track, v4.6) alongside standard scoring** — the industrial-calibrated Basis/Yield floors below remain the deal's governing test, but a parallel land/redevelopment-value read is warranted for this asset subclass; see STAGE 2.9.

## STAGE 1 — FLOORS (flags, not kills — Ruling 5; computed per v1.1-C)

- **Basis floor:** all-in basis (price + 2% closing + CapEx + lease-up carry) discount to replacement, where replacement = **LOW end of the RCT band** (RCT v03: every market is a point ± confidence band — see **Replacement Cost Table (RCT v03)** under UNDERWRITING CONVENTIONS; basis points and floors compute at the LOW end of that market's band). Floor = **linear vintage ramp: 65% at/below 1995 → 60% at/above 2005** (−0.5%/yr). Cite RCT version on every screen. Apply the documented **adder schedule** (heavy office build-out, climate control, cranes, ESFR, excess site work, paving/lighting intensity) instead of ad-hoc overrides.
  - ⚠️ **RAMP RECALIBRATED 2026-07-14 (30/25 → 65/60) — THE FLOOR % AND THE DENOMINATOR ARE A MATCHED PAIR.** The old 30/25 ramp was calibrated against RCT v02's *understated* denominator. RCT v03 corrects that denominator (roughly doubling it, per the coherence test). Leaving the ramp at 30/25 against the corrected table would have set the Columbus floor at **$160.76/SF** — a price at which *every* candidate in the buy-box "clears." **A floor that passes everything is not a floor.** The ramp was therefore re-solved to preserve the firm's *revealed* selectivity: ORA's existing clearing prices imply a **mean ~64% discount** to true replacement, not 25–30%. **The 25–30% language was an artifact of a wrong denominator, never a statement of the strategy.** ORA buys at roughly **35–40% of true all-in replacement cost** — say that in IC memos and lender packages; it is a far stronger fact than "a 25% discount."
  - **Net effect of the correction** (v02+30/25 → v03+65/60): **Maryland tightens ~23%** (it had been the most over-generous market) · **Grand Rapids loosens ~16%** and **Indianapolis ~7%** (both had been unfairly harsh) · Columbus, KC and Madison tighten modestly (~3–8%) · Richmond and Des Moines are ~flat. Every move is in the direction the primary-source evidence demands.
- **Renovation effective-vintage rule (Waukee IA audit finding, resolved):** a material renovation shifts the year used for the vintage ramp. Compute renovation spend as a % of that market's RCT v03 POINT replacement cost ("R%"). **R% < 5%** → routine capex, no shift, use the actual year built. **R% ≥ 25%** → full reset, use the renovation-completion year as the effective vintage (treat as newly built for ramp purposes). **5% ≤ R% < 25%** → linear interpolation: effective vintage year = actual year built + [(R% − 5%) ÷ (25% − 5%)] × (renovation year − actual year built). Example: a 1991 building with a 1998 renovation costing 30% of RCT v03 POINT clears the 25% full-reset threshold → effective vintage = 1998. Document R%, the renovation year, and the resulting effective vintage on every screen where this rule is invoked; unverified/asserted renovation spend gets [est] and blue-cell discipline like any other input.
- **DENOMINATOR-SENSITIVE flag (v1.1-C-iii):** any deal within ±5 discount-pts of its floor (at point or low end) OR whose floor verdict flips between point and low end → local replacement verification (insurance comp or contractor quote) REQUIRED pre-LOI.
- **Yield floor:** stabilized YoC >8% on full all-in (prefer 10%+). **Ruling 1: at the walk price, score Yield as-is — 0 pts when the YoC floor binds; no midpoint adjustment.**
- **IRR floor:** levered ≥15% (5-yr) / ≥12% (10-yr); interpolate; risk-adjust up.
- **DSCR floor (per-property governor — v3.8; reported on every UNDERWRITE, not just at refi sizing):** post-refi DSCR must be ≥1.25x at the market-rate refi terms in UNDERWRITING CONVENTIONS (LESSER of 65% LTV per-property and 1.25x DSCR). Report actual computed DSCR alongside the IRR floor line on every screen and underwrite. Breach = flag (Ruling 5), not kill, but state the compensating factor if pursued. This and the IRR floor are the two Stage 1 floors computed with debt layered in; Yield and Basis remain unlevered (see UNDERWRITING CONVENTIONS note). Note: this is the per-property governor — the separate portfolio-aggregate 40% LTV governor is checked at STAGE 2.3, not here.
- **Carrying-cost floor (FLAG, not kill — per Ruling 5):** stabilized total OpEx ≤ **$4.00/SF/yr**, computed on the **pro-forma reassessed property tax at ORA's purchase price** (never the seller's in-place bill) per the State Reassessment Matrix below. Above $4.00/SF → label **CARRY-FLAGGED**; state which component drives the overage and how recovery structure (NNN vs. gross/MTM, vacancy carry) absorbs it. Reassessed tax flows through NOI → the Yield and IRR floors automatically (no double-count).
- **Portfolios:** every building individually clears floors at its **allocated price**, then score the blend. **Allocation method (in priority order):** (1) if credible per-building NOI exists → allocate by **stabilized NOI share**; (2) if NOI is missing or unreliable → allocate by **replacement-cost-weighted GBA** (building SF × RCT v03 POINT for that market ÷ Σ across all buildings); (3) fall back to **raw GBA share** (building SF ÷ portfolio SF) only when construction quality is unknown. State which method was used. A vacant building in an otherwise-leased portfolio is always allocated by method (2) — method (1) would assign it near-zero basis, which is incorrect.
- **Unpriced/no-NOI:** solve walk price to the 8% YoC floor; gap-to-ask = negotiability flag, not a score.
- **Mezzanine (Ruling 2):** partial SF credit ONLY if conditioned + code-compliant egress + leasable; credit % = expected mezz rent ÷ ground-floor rent, **capped at 75%**; otherwise 0% + removal CapEx if dysfunctional.

## STAGE 2 — SCORECARD (100 pts; REPORT AS QUALITY + ECONOMICS + COMBINED per v1.1-A)

**Quality (price-independent, max 55 always)** = Product 20 + Market 12 + Seller 10 + Tenancy 7 + VA 6–13. **Vacant-deal arithmetic (Waukee IA audit finding, resolved):** the prior "62 if vacant" figure was wrong — it double-counted Tenancy's points instead of reallocating them. When 100% vacant, Tenancy scores 0 (no in-place tenant to score) and VA absorbs Tenancy's forfeited 7 pts 1:1 (VA 6 → 13, per the scorecard table row 7). Quality max is **55 in every case** — vacancy shifts points between Tenancy and VA, it never adds points — which is what makes Combined = Quality(55) + Economics(45) = 100 close correctly in both the occupied and vacant case.
**Economics (price-dependent, max 45)** = Basis 25 + Yield 20, at the ORA-actionable price.
**Combined = Quality + Economics** (identical to the v1.0 100-pt score). Unpriced deals rank primarily on Quality; show Economics as a band across the plausible price range.

**Levered IRR reporting (v3.8):** report levered IRR — 5-yr and 10-yr, both pre-tax and after-tax/cost-seg scenarios — alongside Combined and Expected Score on every SCREEN and SNAPSHOT output, not only UNDERWRITE/FULL, so return dispersion is visible for pipeline triage even between deals with similar Combined scores. IRR remains floor-only (Stage 1), NOT point-scored — scorecard weights are unchanged from v1.1. Converting IRR from floor to a scored Economics component is a calibration-governed decision reserved for the annual December back-test (Outcome Feedback, v1.1-E); do not hand-adjust weights mid-cycle.

**Batch-ranking compression flag — Yield = 0 (v3.4):** when >50% of deals in a ranked batch have Yield = 0 (no NOI disclosed), the ranking is driven by Quality + Basis only — not a full 100-pt scorecard. Flag this explicitly at the top of any batch-ranking output. Relative rank within a ≤5-pt Combined band is below estimation precision when Yield is uniformly zero. Prioritize deals with NOI disclosure for broker call time; call out any deal where a disclosed yield would materially move rank.

**Clear/loading matrix:** units <3,500 SF → 14'+ clear; 3,500–10,000 → 16'+; >10,000 → 18'+ (higher better). Loading: 1 drive-in per unit <5,000 SF; 1 dock/10,000 SF; more is better. **Seller/Motivation signals (any credible signal scores; stack for more):** distress/life events (estate/probate, divorce, partnership dissolution, lender pressure/REO, tax delinquency, DM fatigue); market evidence (price cuts, DOM >120, failed contracts, broker churn); inexperience (residential/local-only brokerage on a commercial deal, no/bad OM, unpriced, mispriced vs auditor/comps, $0-basis long-hold non-institutional seller).

**Owner-user-vacating (named signal):** an owner-occupant disposing of its OWN now-vacant building is structurally motivated (carrying a non-income building bleeds an operator) and typically mispriced HIGH at listing (anchored to original cost/replacement, not a lease-up buyer's residual), often paired with inexperienced/local brokerage. Scores high in Seller/Motivation; compounds with DOM>120, price cuts, failed contracts.

### Pipeline stamping (standing rule — added 2026-08-12)

**This skill previously stamped neither field, despite being named as a stamper elsewhere.** `ora-deal-command-board` STEP 2 has described `Last Activity` since 2026-07-17 as "an explicit date stamped by deal owners and deal-touching skills (loi-generation, deal-execution, acquisition-underwriting, etc.)" — but `loi-generation` Phase 6 and `deal-execution`'s NOTION PIPELINE STAMPING section were the only two that actually did it. That gap is closed here; it was never a decision, only an omission.

Any time this skill acts on a deal that has an Acquisition Pipeline Tracker row (`bcfe4a03`) — a SCREEN verdict, a COMPS refresh, an UNDERWRITE, or a FULL IC memo — update that row:

- **`Last Activity` = today (date-only).** A screen or an underwrite IS deal progress. Without this stamp the work is invisible to the weekly board, which reads `Last Activity` and not Notion's system last-edited timestamp, so a deal under active underwriting false-flags STALLED — the exact 754 Old State Route 74 failure documented in `deal-execution`. Underwriting that happens off-Notion (in the model, in a memo) is precisely the case this field exists to cover.
- **`Next Action Date` — only when the verdict carries a date.** Write it into the column, never only into `Next Action` prose. Realistic cases: a T2 WATCH verdict with a re-check date, a STAGE 2.6 pre-LOI DD item with a deadline, an LOI decision date. **If the verdict carries no date, leave the column NULL** — do not invent one, and specifically do not manufacture a date from the tickler habit ("re-check in 30 days") unless that re-check was actually decided. A fabricated date on a live deal record is a Hard-Invariant-7 fabrication, and it is worse than a null here because two downstream tasks now treat this column as a commitment: `ora-deal-aging-sla` STEP 3d flags a past-due date as a missed self-imposed commitment, and `ora-health-guard` block 4d runs its 7-day deadline sweep off it.
