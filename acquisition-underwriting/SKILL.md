**RULE EVIDENCE (v4.35, Gabriel in-turn 2026-10-23).** Every doctrine change entry (new rule, changed constant, new gate, new floor, new weight) carries one Rule Evidence line in `versions/CHANGELOG.md`. A rule without one is INCOMPLETE and is not merged.

| Field | Content |
|---|---|
| Evidence ID | `RE-<version>-<n>`, unique |
| Incidents | Count of INDEPENDENT deals or events that exposed the problem, each with date and deal. Two findings on one deal count once. |
| Expected loss | probability x severity, in $ per deal and per year, with the source of each factor; `[UNQUANTIFIED]` is allowed but must say what would quantify it |
| Evidence class | `ORA-OBSERVED` · `EXTERNAL-ANCHORED` (cited public benchmark) · `THEORY` (mechanism only) · `RATIFIED-JUDGMENT` (Gabriel's decision with no data yet) |
| Testable | The metric and dataset that will confirm or refute it (e.g., `BackTestDataset / Variance_Review line "Renewal rate"`) |
| Sunset review | Date; default the December back-test that follows the next 12 months of data |
| Ratifier / date | Who, when, and whether in-turn |

**Admission rule (ratified 2026-10-23):** a change to a floor, weight, constant or gate is admitted when it has **at least 2 independent incidents OR a quantified expected loss of at least 0.5% of median deal price per deal**. A **single-incident** rule is allowed when tagged `EVIDENCE: SINGLE-INCIDENT` and given a sunset at the next December back-test (it then gains a second incident or is reviewed for retirement). **Exempt from the count** (they still carry the field): legal and safety rules, data-integrity guards, wording or naming-only changes. **Gabriel's in-turn ratification is always sufficient**; the field then reads `RATIFIED-JUDGMENT`. At each December session the back-test dataset (`references/outcome-feedback-and-backtest.md`) records CONFIRMED / REFUTED / INCONCLUSIVE next to every Evidence ID whose Testable metric now has data.

## STAGE -1 — INTAKE RULES (v1.1-G; mandatory before any score is quoted)

**Read `references/doctrine-rationale-and-incidents.md` before disputing or extending any item below.**

1. **County-auditor year-built lookup** for every parcel (**Jefferson County KY / Louisville, v4.40:** PVA building data is paywalled and ORA does not subscribe — Gabriel 2026-10-29; use the Jefferson County Clerk deed search per deal for vintage and deed history, and the public LOJIC ArcGIS layers for zoning, form district, binding plans, flood and fire district) — the vintage ramp needs a real year; UNK defaults to 1995 (the ramp's oldest endpoint, a **65% discount floor**) and is flagged in QUESTIONS FOR GABRIEL.
2. **Load-bearing rent/NOI verification:** the NOI figure must be verified against a source document (rent roll, lease, income statement) BEFORE any score is quoted. Basis + Yield share one denominator — 45 correlated points ride on it. Unverifiable → score carries [est] and blue-cell discipline; say so wherever the score appears.
3. **Dual-brokerage price conflict check (v3.4):** more than one active listing at different prices → halt Economics scoring (Basis and Yield) until the authorized listing agent and current ask are confirmed. Document which listing carries NOI (no NOI → no Yield score). Never average conflicting prices or assume the lower is current without direct broker confirmation. Record discrepancy + source in QUESTIONS FOR GABRIEL.
4. **Data Provenance & Conflict Register (v4.0):** any two sources disagreeing on a load-bearing field (year built, GBA/office SF, clear height, power, cranes, any material physical/vintage fact — not just price) → log it (field / OM value / CoStar value / county-auditor value / value used / basis for choice). Required on every FULL-mode memo (IC MEMO §3) when a conflict exists; never silently pick one source. Default: county-auditor wins on vintage/legal facts; on-site observation or a signed lease overrides an OM claim; state the basis in every row.
5. **Deal-decision-ledger precedent check (v4.2; SCREEN mode only, before scoring):** read `memory/deal-decision-ledger.md` in full; a candidate sharing geography, asset type, seller-motivation signal, or a named rule with a prior decided row is a precedent hit — cite matching rows by date + deal name in the output scorecard (Stage 2 block). "No precedent rows found" is a valid outcome — say so explicitly.
6. **SF/GBA ingestion-time variance check (v4.6):** diff every disclosed building SF/GBA figure across OM, CoStar and any county/parcel record in hand; variance = |max − min| ÷ min. **≤2%** → proceed. **>2% and ≤5%** → proceed, flag variance + figure used in QUESTIONS FOR GABRIEL and the Conflict Register. **>5%** → **HARD STOP:** halt Basis and Yield scoring, cap the verdict at **T2 WATCH**, resolve (county record, survey, or direct broker confirmation) before Combined is finalized. Distinct from STAGE 2.6 item 3 (LOI-stage, >2%).
7. **Scanned / no-text-layer OM check (v4.7):** run `pdfinfo` on every uploaded OM before extraction. Producer "Microsoft: Print To PDF" (or any rasterizer), or empty `pdftotext` → **no text layer**: extract by page-image render (`pdftoppm -png -r 110`) and visual read, page by page — a failed text pull is NEVER evidence of an empty document. Tag every such figure `[OM-visual]` and reconcile per Rule 4.
8. **Zoning district + current assessed value at intake (v4.14):** record for every parcel (i) the **zoning district from the municipality's live zoning GIS layer** (never the assessor's field) via `ora-flood-zoning-dd`, and (ii) the **current assessed value and tax bill on the roll** via `ora-millage-lookup`. Catches (a) an industrial building in a **commercial/mixed-use district** — legal nonconforming, with a 12-month (WI/OH/IN) discontinuance clock that turns re-letting into re-entitlement, a basis-level fact; (b) an **anomalous assessment** (exempt coding, $0 value, stale/absent record) that invalidates any trended pro-forma tax and can carry retroactive omitted-property exposure. Either caps the verdict at **T2 WATCH** until resolved and goes in QUESTIONS FOR GABRIEL. Fires on every mode.
9. **Ancillary-income lease abstraction (v4.30).** For every cell-tower, billboard, solar, rooftop-antenna or easement agreement, record: premises area (the legal-description figure governs over a body-text approximation); rent commencement and whether it has started; initial term **and every renewal option** (count × length, automatic or at tenant election); escalator; **termination rights** (who, notice, fee, and whether the right is at will); ROFR/ROFO on a sale of the fee or the rent stream; relocation rights; and assignment/estoppel mechanics. Model the **full contractual stream**, not a 10-year schedule. Where the tenant can terminate at will, carry a termination case in the Bear scenario and say so. A rent stream carved out of the sale ("towers sold separately") is removed from NOI and logged in the Conflict Register (Rule 4). Origin: 8625 Troost Ave (2026-10-17). The AT&T Option & Land Lease runs 5 + 17 × 5 years with +10% per term and is terminable on 60 days plus three months' rent, but the model's Inputs schedule stopped at 2037.
10. **Recent-acquisition check (v4.37).** For every parcel, pull the last recorded sale price and date from the county parcel/CAMA or recorder record (the same pull as Rules 1 and 8). If the seller acquired **≤24 months** before the screen date: (i) report **ask vs. seller's basis** ($ and %) on the verdict line and in IC memo §1; (ii) carry the recorded sale as an executed comp row in the Discount Decomposition (a) even when no other comp grid exists; (iii) a recent buyer marking up its own basis is **not** a Seller/Motivation signal and caps P(exec) placement at the band midpoint unless an independent signal exists; (iv) if the ask exceeds the seller's basis by >10% with no evidenced capital spent or leases signed since the sale, say so in the pre-mortem. A sale price missing from the record → `[DATA-GAP: last sale]` in QUESTIONS FOR GABRIEL. Origin: 211 Piper Circle (2026-10-27) — county record showed a $2,450,000 sale on 10/1/2025 against a $2,950,000 ask; ORA's binding walk was $2,399,818 before the v4.37 construction-type multiplier (about $2,154,977 after it, PEMB ×0.90).
11. **Replacement-cost source before any proxy (v4.37).** For a market without an RCT v03 row, look up the metro in `references/cw-2025-construction-costs.json` (45 markets, small/med/large 2025 tiers) **before** assigning a `[PROXY]`, and derive LOW/POINT/HIGH with the table's own method (b = ln(small/med) ÷ ln(476,400/109,200); POINT = small × (109,200/40,000)^b × 1.30 × 1.0487; LOW = 0.90 × POINT; HIGH = 1.10 × POINT). Carry the result as a **PROVISIONAL** row cited "C&W 2025 [market]" until Gabriel ratifies it. Origin: 211 Piper Circle — "PENN CORRIDOR" ($133.70 small tier) was in the file; a Baltimore proxy would have been unnecessary.

## STAGE 0 — GATES (Ruling 5: NO HARD KILLS — breaches are FLAGS, screened as exceptions; only Gabriel kills a deal)

A gate breach = prominent flag + screen/score as exception anyway; verdict label **GATE-FLAGGED** (never KILLED). Pure out-of-market junk gets flagged-and-deprioritized rather than scored in depth. **Institutional benchmark note (v4.3):** banks (OCC Handbook) hard-gate environmental, structural and zoning defects; Ruling 5's flag-not-kill is a **deliberate, correct divergence** that lets an all-cash generational-hold family office look at deals a bank must auto-reject — never let an "institutional hardening" pass walk it back.

1. **Product:** Class B/C industrial — shallow-bay multi-tenant, flex, office-warehouse, OR functional single-tenant ≤40,000 SF (scored EQUAL to multi-tenant). Quasi-IOS single-tenant <20K SF on land-heavy parcels = explicit target profile. Office % never kills if 1-story with adequate clear behind the finish (demo-able); ≤30% ideal.
2. **Size/Price:** $500K–$10M single asset; ≤$15M multi-building portfolio of **2–5 buildings sold together (Amendment H)**; <50,000 SF per building. A portfolio over $15M or over 5 buildings = gate flag (Ruling 5: surfaces for Gabriel's call, never a kill; Gabriel in-turn 2026-10-30).

## STAGE 1 — FLOORS (flags, not kills — Ruling 5; computed per v1.1-C)

- **Basis floor:** all-in basis (price + 2% closing + CapEx + lease-up carry) discount to replacement, where replacement = **LOW end of the RCT band** (RCT v03: every market is a point ± confidence band — see **Replacement Cost Table (RCT v03)** under UNDERWRITING CONVENTIONS; basis points and floors compute at the LOW end of that market's band). Floor = **linear vintage ramp: 65% at/below 1995 → 60% at/above 2005** (−0.5%/yr). Cite RCT version on every screen. Apply the documented **adder schedule** (heavy office build-out, climate control, cranes, ESFR, excess site work, paving/lighting intensity) instead of ad-hoc overrides. **Construction type (v4.37):** multiply the RCT POINT by the Construction-Type Multiplier before the adders; LOW is then re-derived, and everything on this line uses that adjusted LOW.
  - ⚠️ **RAMP RECALIBRATED 2026-07-14 (30/25 → 65/60) — THE FLOOR % AND THE DENOMINATOR ARE A MATCHED PAIR** (the 30/25 ramp belonged to RCT v02's understated denominator). **ORA buys at roughly 35–40% of true all-in replacement cost — say that in IC memos and lender packages**, never "a 25% discount" (a wrong-denominator artifact).
- **Renovation effective-vintage rule:** renovation spend as % of the construction-type-adjusted RCT v03 POINT (POINT × multiplier + adders; "R%"). **R% < 5%** → no shift. **R% ≥ 25%** → full reset to the renovation-completion year. **5% ≤ R% < 25%** → effective vintage = actual year built + [(R% − 5%) ÷ 20%] × (renovation year − actual year built). Document R%, renovation year and effective vintage on every screen invoking it; asserted spend gets [est] and blue-cell discipline.
- **DENOMINATOR-SENSITIVE flag (v1.1-C-iii):** any deal within ±5 discount-pts of its floor (at point or low end of the construction-type-adjusted band) OR whose floor verdict flips between point and low end → local replacement verification (insurance comp or contractor quote) REQUIRED pre-LOI.
- **Basis sensitivity line (v4.35 — REPORTING ONLY; Gabriel in-turn 2026-10-23; RE-4.35-2):** on every screen and IC memo report Basis points and the discount-to-replacement computed at the construction-type-adjusted LOW, POINT and HIGH (POINT × multiplier + adders, ±10%; equals the bare RCT v03 band when the multiplier is 1.00 and no adder applies), one line, with the vintage floor used. It takes no part in any score, floor, walk price, P(exec) or verdict, which still use the LOW end. Purpose: make visible that a ±10% denominator error moves Basis by up to roughly 7 of 25 points near the floor.
- **Yield floor:** stabilized YoC >8% on full all-in (prefer 10%+). **Ruling 1: at the walk price, score Yield as-is — 0 pts when the YoC floor binds; no midpoint adjustment.**
- **IRR floor (v4.33 — unlevered; Gabriel 2026-10-18):** 10-yr **unlevered** IRR (all-cash basis, exit at the market exit cap in UNDERWRITING CONVENTIONS) ≥ the **greater of 10.0% and the 10-yr U.S. Treasury + 550 bps**. UST = FRED `DGS10`, trailing 30-day average as of the screen date; cite value and date on the floor line. FRED unreachable → test at 10.0% and tag `[UST UNVERIFIED]`. **Majority-vacant premium (v4.40, Gabriel 2026-10-29): when >50% of the SF is vacant at close, add +100 bps — floor = MAX(10.0%, UST + 550 bps) + 100 bps — codified, not per-deal.** Any other premium (C-class, FORT C+-or-worse, office/off-cluster) stays per-deal judgment; state it each time and never stack it silently on the vacancy premium. **Levered IRR is reported, not a floor** (retired: levered ≥15% 5-yr / ≥12% 10-yr): ORA's actual aggregate LTV is near 19%, so a floor computed on a 65% LTV refi measured a capital structure the family does not hold, and a 5-yr IRR is driven mostly by an exit a generational holder does not plan. **Two tiers by design (v4.34, Gabriel 2026-10-19):** this 10.0% acquisition floor is deliberately HIGHER than ORA's portfolio capital-allocation hurdle — **8.0% unlevered IRR, ratified 2026-06-22** (`capital_config` v1, `ratify-hurdle-rate`). New acquisitions carry execution and lease-up risk the existing portfolio does not, so they clear a higher bar. The two are not a conflict; never flag the gap or 'reconcile' one to the other, and never apply 8% to an acquisition floor test. Either number changes only by Gabriel's in-turn ratification.
