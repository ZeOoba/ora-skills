Top margin is 1.50" to clear the pre-printed letterhead band. Confirm against physical stock — if
the engraved art extends past 1.50", raise it; each letter carries roughly 0.50" of headroom.

## Typography

- Face: **EB Garamond** throughout.
- All text 11 pt (sz 22).
- No typeset firm name or tagline — the pre-printed letterhead carries ORA branding.
  The plain-paper variant (`LETTERHEAD_MODE = "plain"`) sets firm name 15 pt bold Navy #1B2A4A,
  tagline 9.5 pt italic Navy, and drops the top margin to 1.00".

## Structural rules

1. **One letter per page.** `pageBreakBefore` on the first paragraph of each letter. Never a manual
   `<w:br w:type="page"/>`.
2. **No street address in the signature block.** Contact block is exactly: name / firm / cell /
   email / web. The DC address was struck 2026-08-24 — the letterhead carries it. (This supersedes
   the 2026-07-11 note in `owner-outreach` SKILL.md that the "street-address footer" was unchanged.)
3. **Signature gap is 46 pt** — roughly four 11 pt lines, sized for a wet signature.

## Line-budget rules — the two observed overflow modes

`MAX_LINE_CHARS = 76`. Calibrated against the 2026-08-26 pack at the geometry above: every letter
whose Re: line rendered at **≤ 61 characters fit one page**; every letter at **≥ 80 characters
wrapped** and pushed the P.S. to a second page. 76 sits in that gap with margin either side.

**Mode 1 — the Re: line wraps.** Four of five overflow letters.
A "(+N more)" cap past three properties already existed in the generator and did **not** prevent
this: three long addresses still render at 87 characters. Property *count* is the wrong lever;
rendered *length* is the binding constraint. `fit_re_line()` drops properties from the visible list
until the whole line fits, rolling each dropped one into the "(+N more)" tail.
`prose_property_list()` mirrors that truncation so the Re: line and the body never disagree about
how many properties the letter concerns, and returns the property/properties word so both body
mentions agree.

**Mode 2 — the address block wraps.** One of five (Sheldon C Tyler & Gwyneth Ann).
The Tier-0 mailing parse emitted a street field that repeated the mailing name and then appended a
capacity phrase — `Sheldon C Tyler & Gwyneth Ann CO Trustees Et Al 5180 Golden Foothill Pkwy Suite
210`, 82 characters. `split_address_block()` peels the duplicated name, lifts the capacity phrase
onto its own attention line, and leaves a clean street line. This is also a mailing-quality fix:
that string would have printed badly in a window envelope regardless of pagination.

**Fallback (last resort).** A letter that still will not fit gets per-letter tightening — space-after
200→100, 160→100, 120→80, signature gap 920→680 — applied **to that letter only**. Never shrink the
font. Never apply the tightening pack-wide. Never let a letter run to two pages.

## Integrity gate (mandatory, post-generation)

`verify_pack(pdf_path, expected_letters)` renders and asserts `pages == letters + 1` **and exactly
one salutation per letter page**. Page count alone is insufficient — it passes when one letter
spills while another is short. Hard-fail on a problem, same severity as the existing letter-count
integrity check. On the 2026-08-24 pre-fix build this gate caught all five overflow letters; page
count alone would have reported only "161 vs 157" with no idea which letters were broken.

## Content tokens (template)

| Token | Meaning |
|---|---|
| `{{LETTER_DATE}}` | Long-form date, e.g. August 26, 2026 |
| `{{OWNER_NAME}}` | Mailing name from the Tier-0 queue |
| `{{OWNER_ADDR1}}` | Street (after `split_address_block`; attention line inserted above when present) |
| `{{OWNER_CITY_STATE_ZIP}}` | Owner mailing city/state/ZIP |
| `{{SALUTATION}}` | "Owner of <first property>" or the `principal-overrides.csv` named form |
| `{{PROPERTY_LIST_DOT}}` | Re:-line list from `fit_re_line()` |
| `{{PROPERTY_LIST_PROSE}}` | Body list from `prose_property_list()` |
| `{{PROPERTY_WORD}}` | "property" / "properties" — same value in both body mentions |
| `{{MARKET}}` | Market name, e.g. Columbus |
